# ❤️‍🔥 戀愛巴士表單 Love Bus Form

看膩醜醜的谷歌表單了嗎？

因朋友要辦戀愛巴士聯誼需要因此我做了

一個以戀愛配對為主題的互動式網頁表單，使用 HTML / CSS / JavaScript 製作，支援 RWD 響應式設計，適合手機與桌面瀏覽。

## ✨ 專案特色

* 🎨 動態切換表單動畫
* 📱 RWD 手機版支援
* 💌 戀愛風格 UI 設計
* 🔥 流暢滑動與轉場效果
* 📋 表單資料收集功能（google 表單）
