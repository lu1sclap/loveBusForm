# ❤️‍🔥 戀愛巴士 Love Bus

一個以戀愛配對為主題的互動式網頁，使用 HTML / CSS / JavaScript 製作，支援 RWD 響應式設計，適合手機與桌面瀏覽。

## ✨ 專案特色

* 🎨 動態切換表單動畫
* 📱 RWD 手機版支援
* 💌 戀愛風格 UI 設計
* 🚌 主題式互動體驗
* 🔥 流暢滑動與轉場效果
* 📋 表單資料收集功能

## 🚀 使用方式

### 1. Clone 專案

```bash
git clone https://github.com/你的帳號/love-bus.git
```

### 2. 開啟專案

直接打開：

```bash
index.html
```

即可在瀏覽器查看。

---

## 🌐 GitHub Pages 部署

進入：

```txt
Settings → Pages
```

設定：

```txt
Source → Deploy from a branch
Branch → main
Folder → /root
```

完成後即可透過：

```txt
https://你的帳號.github.io/love-bus
```

瀏覽網站。
